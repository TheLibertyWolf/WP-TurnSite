# Support

Avant de demander de l’aide :

1. vérifiez que le domaine figure dans les noms d’hôte autorisés du widget Cloudflare ;
2. testez la clé secrète dans `Réglages → WP TurnSite` ;
3. vérifiez la connectivité HTTPS sortante vers `challenges.cloudflare.com` ;
4. indiquez les versions de WordPress, PHP, WP TurnSite et, le cas échéant, WooCommerce.

Utilisez les [issues GitHub](https://github.com/TheLibertyWolf/WP-TurnSite/issues) pour les bugs reproductibles et demandes d’évolution. N’y publiez jamais de clé secrète ni de vulnérabilité exploitable.
