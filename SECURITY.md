# Politique de sécurité

## Versions prises en charge

Seule la dernière version stable de WP TurnSite reçoit les correctifs de sécurité.

## Signaler une vulnérabilité

Ne publiez pas de vulnérabilité exploitable dans une issue publique.

Contactez SAS Jessy System depuis [jessysystem.com](https://jessysystem.com) en indiquant :

- la version concernée ;
- les étapes de reproduction ;
- l’impact estimé ;
- tout correctif suggéré.

Une confirmation de réception sera envoyée dès que possible. La divulgation publique doit attendre la disponibilité d’un correctif.
