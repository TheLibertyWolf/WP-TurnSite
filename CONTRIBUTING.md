# Contribuer à WP TurnSite

Merci de contribuer à WP TurnSite.

1. Ouvrez d’abord une issue pour les changements fonctionnels importants.
2. Créez une branche depuis `main`.
3. Respectez les standards de code WordPress et PHP 8.1 minimum.
4. Échappez toute sortie, validez les capacités et utilisez une nonce pour toute action sensible.
5. Toute validation Turnstile doit rester côté serveur, vérifier l’action et le nom d’hôte.
6. Mettez à jour les six langues, le README et le changelog pour toute chaîne ou fonctionnalité nouvelle.
7. Soumettez une pull request concise avec les tests effectués.

Les vulnérabilités suivent exclusivement la procédure de [SECURITY.md](SECURITY.md).
